1 · 有边界的 AI 代理

授权允许什么，代理就只能做什么

授权是一份带限制的凭据，在代理要操作的那台机器上签发。那台机器在每条命令、每次文件操作时检查它，代理那边怎么做都扩大不了权限。

  1. 哪些功能、哪些路径

    执行命令、读写指定目录下的文件（只读或可写）、截图、桌面、剪贴板、端口转发。没列出的一律拒绝，包括给自己创建一个比授权活得更久的配对。

  2. 哪些命令

    只允许以指定程序开头的命令。管道、重定向和 $ 都会被拒绝，一条命令没法再启动别的命令。

  3. 能用多久

    授权到期自动失效，它的会话随之结束；remohop host revoke 可以提前结束。

  4. 要不要你批准

    each：每条命令、每次文件改动都要你批准；first：每个会话的第一次要批准。30 秒没人回答就自动拒绝。

  5. 留下记录

    每个操作都以授权名记入被控机的审计日志；加上 --record，命令和终端的输出也会录下来。

一键全停

remohop host panic

立即暂停所有授权，结束所有代理会话。不需要窗口或快捷键，在被控机的任何终端里都能执行，通过 SSH 也行。

代理知道自己的边界

remohop_limits

代理可以查询自己能做什么；每次拒绝都会写明是哪条限制、哪个授权，并告诉代理不要想办法绕过。

授权做不到的事

命令白名单是护栏，不是沙箱：能启动别的程序的命令（make、git 钩子、任何解释器）会把这种能力一起带进来；批准 ./deploy.sh，就是批准了这个脚本做的一切。详见保护的边界（英文）。整个团队用的话，RemoHop 团队版按一套策略签发同样的授权，管理员也可以批准操作。

2 · 一个工具顶几个

远程桌面、终端、文件、端口转发和组网，都在一个程序里

给代理用，也给你自己用。桌面应用、浏览器、手机或命令行都能连接，另一端运行的是同一个 remohop。

direct · 端到端加密

  • 远程桌面在桌面应用或浏览器里：2K 和 4K，局域网约 60 ms，最高 144 fps，有声音，支持多显示器。
  • 终端和后台任务断开后仍在运行的终端、单条命令、带日志的后台任务。Windows 上是 PowerShell。
  • 文件复制、同步、把远程目录挂载到本地；大文件中断后接着传。
  • 端口转发和 VPN像 ssh -L、-R 一样转发 TCP 和 UDP，网络唤醒，还能用 VPN 连进被控机所在的网络。
  • 虚拟组网你的设备组成一个私有网络，名字像 nas.remohop。可以和 Tailscale 一起用，共同的 tailnet 也算一条直连路径。
  • 快速协助被协助的人双击一个程序，把 ID 和密码念给你，每次连接都由他点“允许”。
  • Android 和 iOS 应用用手机控制你的电脑。Android 手机也能被控制，iPhone 和 iPad 可以共享屏幕。
  • 一个静态程序客户端、被控端、汇合服务器、浏览器网关和 MCP 服务器都是同一个 remohop，支持 Linux、macOS 和 Windows。

3 · 可以验证的信任

端到端加密，默认直连，开源，每台服务器都可以自己运行

汇合服务器按 ID 帮两台机器找到对方。之后画面、键盘、文件和命令都走 QUIC 直连，只有两端能读。实在打不通时，中继转发的也是同样的密文。

  • QUIC 加 TLS 1.3，登录用 CPace。密码从不在网上传输；中间人，包括汇合服务器，都无法完成登录。
  • 默认点对点直连。先打洞、请路由器映射端口；只有运营者开启了中继、其他办法都不行时才走中继。
  • 服务器只看到密文和元数据。哪些 ID 在线、它们的地址、何时互相连接；看不到内容。
  • 每次连接都先问你。新设备附防诈骗提醒；允许的设备默认只能看屏幕，其余的要你勾选。
  • 以 AGPL-3.0 开源。汇合服务器、中继和浏览器网关都可以自己运行；局域网里甚至不需要服务器。
还没做到的事
  • 没有经过独立的安全审计。
  • Windows 下载尚未代码签名，SmartScreen 会提示。
  • Linux 是参考平台。macOS 和 Windows 由托管机器上的自动化测试覆盖，还没有人在实体机上逐项检查。
