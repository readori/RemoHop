P2P 直连

服务器只负责牵线，画面直接走两台电脑之间

汇合服务器按 ID 帮两台电脑找到对方，之后画面、键鼠和文件都走 QUIC 直连，TLS 1.3 端到端加密，密码从不在网上传输。实在打不通时才经中继转发，中继也看不到内容。

  1. 1. 牵线两边都连上汇合服务器，按 9 位 ID 找到对方，交换地址。
  2. 2. 打洞同时从两边向对方发包，穿过大多数家用和公司路由器，局域网里直接走内网。
  3. 3. 直连QUIC 加密通道建立后，服务器就退出了；打不通时约 1.5 秒内切到中继。

更清晰、更快、更安全

被控端说了算

每次连接都弹窗询问，新设备附防诈骗提醒；默认只能看屏幕，控制和文件要你勾选，随时收回、随时断开。

2K / 4K 高画质

Intel、NVIDIA、AMD 显卡直接从 GPU 编码，按显示器物理像素采集，文字锐利，码率随网络自动调整。

低延迟

局域网 2K 实测约 60 ms、4K 约 114 ms；关键帧请求无缝切换编码器，锁屏和 UAC 只暂停不断开。

穿透各种网络

P2P 打洞、IPv6、NAT64、UDP 被封时自动改走 WebSocket；换网络、休眠唤醒后自动重连。

不只是桌面

终端、文件传输（断点续传）、剪贴板、端口转发、虚拟组网、网络唤醒，还能交给 AI 代理（MCP）在授权范围内操作。

可以自己部署

可用官方汇合服务器 signal.remohop.com，也可以一条命令自建，一台最小的虚拟机就够；局域网里按地址直连，不用服务器。

快速协助

帮别人操作电脑

对方下载“快速协助”，免安装，双击打开，窗口里大字显示 9 位 ID 和临时密码，念给你听。你连接时对方会看到你的设备名称、密钥和地址，点了“允许”才连得上，60 秒没人答复就自动拒绝。

默认可以看屏幕、用鼠标键盘、传文件；运行命令和访问对方的网络，要对方另外勾选。关掉窗口就停止共享。

你这边用桌面应用、浏览器客户端、手机应用或命令行连接，双方要用同一台汇合服务器。

快速协助说明

桌面应用 / 命令行

连自己的机器

在要控制的机器上打开 RemoHop 桌面应用并允许连接，或者运行 remohop host。配对一次之后，连接不再需要密码；也可以开启无人值守访问。

# 被控机
$ remohop host
# 你的机器
$ remohop 276941009 pair --name dev
$ remohop dev shell
$ remohop web --target dev

同一个局域网里可以不用服务器：被控机运行 remohop host --no-signal --listen :21118，客户端用地址代替 ID。
