English

远程连上你的电脑

用浏览器、手机或命令行操作另一台电脑：看桌面、开终端、传文件、转发端口。两台机器之间直接建立端到端加密的连接，被控机不用注册账号，服务器也由你自己运行。

快速开始 功能与限制

开源（AGPL-3.0）· 一个 Go 程序 · 源码在 GitHub

现状（2026 年 11 月）：首个发布版本正在准备中，在它发布之前需要从源码编译；程序里没有内置的默认服务器，汇合服务器要自己运行；没有经过独立的安全审计。Linux 是参考平台，macOS 和 Windows 只在托管的 CI 机器上跑过自动化测试。完整的限制清单

被控端说了算

被控机的主人可以要求每次连接都在本机点“允许”，逐项关掉功能，随时撤销配对。快速协助的每一次连接都要对方同意。

一个 remohop 程序

被控端、命令行客户端、浏览器网关、汇合服务器和给 AI 代理用的 MCP 服务器，都是同一个静态链接的程序。

可以自己部署

没有内置服务器，也不需要账号。局域网里按地址直连；跨网络时用你自己运行的汇合服务器，一台最小的虚拟机就够。

快速协助

帮别人操作电脑

对方打开 RemoHop 快速协助，窗口里大字显示 9 位 ID 和临时密码，念给你听。你用这两样连接时，对方会看到你的设备名称、设备密钥和地址，点了“允许”才连得上，60 秒没人答复就自动拒绝。

默认可以看屏幕、用鼠标键盘、传文件；运行命令和访问对方的网络，要对方另外勾选。关掉窗口就停止共享。

你这边用命令行、浏览器客户端或手机应用连接，双方要用同一台汇合服务器。

快速协助说明

被控端 + 客户端

连自己的机器

在要控制的机器上运行 remohop host，它给出 ID 和临时密码。在自己的机器上配对一次，之后连接不再需要密码。

# 被控机
$ remohop host
# 你的机器
$ remohop 276941009 pair --name dev
$ remohop dev shell
$ remohop web --target dev

同一个局域网里可以不用服务器：被控机运行 remohop host --no-signal --listen :21118，客户端用地址代替 ID。
