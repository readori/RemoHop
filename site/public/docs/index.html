English

快速开始

这一页只讲从零到第一次连上要做的五步。每个命令的完整语法用 remohop help <命令> 查看，其余内容在按主题分页的文档里，目录在页面下方。

假设有三台机器：一台带公网地址的小服务器运行汇合服务器（下文写作 sig.example.net），一台被控机，一台你自己的工作机。只在局域网里用的话，可以跳过服务器。

1. 安装

在每台机器上用安装脚本（Windows 用 install.ps1）、软件包或下载页上的压缩包安装 remohop：

curl -fsSLO https://github.com/readori/RemoHop/releases/latest/download/install.sh
sh install.sh

它会把 remohop 放到 ~/.local/bin（root 用户为 /usr/local/bin）。想自己编译，见从源码编译。

2. 运行汇合服务器

在有公网 IP 的机器上开放 UDP 端口 21116 和 21117，然后运行：

remohop signal

服务器启动时会打印自己的公钥，客户端可以用 remohop config set signal-pin KEY 固定它。要为无法直连的会话提供中继，改用 remohop signal --relay。长期运行见自建服务器。

3. 启动被控机

remohop config set signal sig.example.net
remohop host

remohop host 在前台运行，打印 ID 和临时密码。想开机自启就装成系统服务：

remohop service install
remohop status --show-password

它会写入 systemd 单元（Linux）、launchd 任务（macOS）或 Windows 服务。服务有自己独立的身份、ID 和密码，和手动启动的 remohop host 不是同一个实例。系统级服务和 Windows 服务看不到桌面会话，需要截图或远程桌面时请用用户级服务。在 Windows 上，remohop service install --unattended 则让服务的客户端看到控制台会话，包括登录界面、锁屏和 UAC 提示（默认关闭）；桌面应用的“无人值守访问”就是这样安装的。

需要固定密码时执行 remohop passwd，它以不回显的方式询问，之后也不会再把密码打印出来。

4. 连接并配对

remohop config set signal sig.example.net
remohop 276941009 ping
remohop 276941009 pair --name dev
remohop dev info
  • ping 显示到被控机的路径。第一次连接需要密码，它会提示输入。
  • pair --name dev 只需输入一次密码，随后在本机保存一个绑定到本机身份的配对令牌，并保存别名 dev。
  • 之后 remohop dev ... 不再需要密码。remohop devices 列出已保存的主机以及它们是否在线。

5. 开始用

remohop dev shell                       # 持久终端；先按回车再输入 ~. 分离
remohop dev cp ./build.tar.gz :/tmp/    # 远程路径以 : 开头
remohop dev forward -b 18080:8080       # 把远程的 8080 映射到本机 18080
remohop dev desktop                     # 在浏览器里查看并控制远程屏幕
remohop web --target dev                # 浏览器客户端：桌面、终端、文件、剪贴板

不用服务器：局域网或公网 IP 直连

能直接通过地址访问被控机时，不需要汇合服务器。在被控机上：

remohop host --no-signal --listen :21118

在客户端用地址代替 ID，仍然需要密码：

remohop 192.168.1.5:21118 pair --name lab
remohop lab info

让 AI 代理使用

先配对，再把 MCP 服务器加进代理宿主程序。以 Claude Code 为例：

claude mcp add remohop -- remohop mcp --target 276941009

读取 mcpServers 配置的客户端（例如 Cursor）：

{
  "mcpServers": {
    "remohop": { "command": "remohop", "args": ["mcp"] }
  }
}

代理会以运行被控端的那个用户的权限在远程机器上操作。只为希望代理访问的机器配对，关掉它用不到的功能（例如 remohop config feature input off），不再需要时用 remohop host revoke 撤销。

完整文档

使用指南按主题分页，中英文两个版本内容相同；深入的参考文档目前只有英文。遇到错误时先看故障排查（英文）。

远程命令的格式都是 remohop <ID> <command>。各页的例子用 dev 作为别名，它来自 remohop <ID> pair --name dev。每个命令的完整语法用 remohop help <command> 查看。
