文档

桌面应用

一个窗口，既能连接你的其他电脑，也能让别人连接这台电脑，支持 Windows、macOS 和 Linux。下载中的 RemoHop.exe、RemoHop.app 和 remohop-app 就是它（见安装），在终端里是 remohop app。

首页有人请求连接
连接在窗口中打开的电脑

左侧边栏依次是首页、连接和会话，然后是窗口中打开的每台电脑，最下面是设置和这台电脑的状态。窗口较窄时，或点标志旁的按钮，边栏会收成一列图标。

第一次启动

应用会询问语言（或跟随系统）和汇合服务器，也就是按 ID 为电脑牵线的服务：官方服务器（signal.remohop.com）、你自己的服务器（见自建），或暂时不用。不用服务器时按地址（主机:端口）连接，这台电脑也可以在本地网络中按地址访问。之后可在“设置”中更改；它与 remohop config set signal 是同一个设置。

这一页上有个选项可以立即允许别人连接；否则在你打开之前，别人都连不上。

连接

输入 9 位 ID、你给电脑起的名称或 主机:端口，或者从已保存的电脑中选择（连接过或配对过的电脑，以及账号中的设备），每台都显示是否在线。它的菜单（⋮）可以重命名、移除、保存网络唤醒的 MAC 地址并唤醒它。

每台电脑都在窗口中打开，并列在边栏的“已打开的电脑”下，里面是熟悉的桌面、终端、文件、剪贴板和信息（见远程桌面、浏览器客户端）。没有记住的登录时会要求输入密码。勾选记住这台电脑后，应用会和它配对；对方不支持配对时（快速协助、另一台电脑上的桌面应用），就把密码保存在本机，下次自动登录，直到对方换了密码。输入框里的眼睛按钮可以显示输入的密码；在已保存的电脑里，⋮ 可以查看或删除保存的密码。⧉ 把这台电脑移到单独的窗口；× 断开并关闭它。首页上也有“快速连接”输入框，以及最近在线的电脑。连接断开（睡眠、换了网络）后会自动恢复。

首页：这台电脑

  • 允许别人连接。默认关闭。打开后，首页显示这台电脑的 ID 和临时密码（每次启动都会换新，“换一个”立即更换），都带复制按钮。
  • 每次连接都会询问。无论在哪个页面，都会弹出对话框：谁在请求（对方自称的名称、密钥和地址）、是否是新设备；对新设备还会提醒：有人打电话自称客服、银行或警察，让你安装远程软件，那是诈骗。被允许的设备只能看屏幕，除非你勾选“控制鼠标和键盘”或“传输文件、使用剪贴板”。一分钟内没人回答的请求会被拒绝。“记住这台设备”让它下次以相同权限直接连入（在允许连接打开时）；已记住的设备会列出来，可以移除。
  • 会话页面显示等待回答的请求（以及各自剩余的时间），当前连接列出每台设备，带“控制”和“文件”开关（立即生效，收回的权限会结束正在使用它的操作）和“断开”。只能查看的设备可以从它那边请求更多权限，这里会再问你一次。有人连接时边栏的“会话”上有红点，屏幕右下角有一个小横幅始终显示在所有窗口之上，带“断开”按钮。
  • 无人值守访问让这台电脑在没人时也能连上，开机即可用，使用你设定的强密码（至少 12 个字符，包含三类字符）。它把 RemoHop 安装为服务（remohop service install）：在 Windows 上是 RemoHop 服务，还能显示登录界面和 UAC 提示；在 macOS 和 Linux 上是你用户账号的服务。首页上的开关开启时为绿色、关闭时为红色。无人值守 ID（在 Windows 上服务有自己的 ID，不是应用的 ID）和无人值守密码在设置 > 无人值守 ID 与密码里查看；密码默认隐藏，点“显示”才出现，一分钟后自动隐藏。“连接”列出通过它连接的人（可断开），“修改密码”可更换密码。应用本身从不以管理员身份运行：在 Windows 上服务的状态只属于管理员，所以这些操作（开启或关闭、显示密码、查看连接、断开、设置新密码）都会在当时请求管理员授权。

设置

汇合服务器、语言（中文、英文或跟随系统）、浅色或深色（或跟随系统），以及登录时启动 RemoHop（启动后只在托盘中，不显示窗口）。

更新

应用启动后不久以及之后每天一次，从 https://remohop.com/version.json 读取最新的版本号（请求不带任何标识）。有更新的版本时，页面上方会出现一条提示，带下载（打开下载页）、更新内容（发布说明）和 ×（跳过这个版本）。用 Homebrew、Scoop、winget 或 Snap 安装的，提示里给出对应的升级命令（brew upgrade --cask remohop-quick、scoop update remohop、winget upgrade RemoHop.RemoHop、sudo snap refresh remohop）；用 .deb 或 .rpm 安装的，请用系统的包管理器升级。从官网下载、放在你有写权限的文件夹里的版本，还会有立即升级：应用从 GitHub 下载新版本，只有发布的签名校验和（用内置在 RemoHop 里的 Ed25519 公钥验证）与它一致、并且在 macOS 上由 RemoHop 开发者签名时才接受，然后替换自己并重启。有人连接着这台电脑时不会升级；不点这个按钮，应用不会下载或安装任何东西。

设置 > 更新可以关闭每天的检查，也可以立即检查。管理员可以设置环境变量 REMOHOP_NO_UPDATE_CHECK=1 统一关闭。开着无人值守访问的电脑，升级后请把它关闭再打开一次，让服务运行新版程序。

窗口、托盘与后台

关闭窗口后 RemoHop 会留在托盘（macOS 上是菜单栏）中继续运行，别人仍可连接；托盘菜单中的“退出”会结束它和所有连接。再次启动 RemoHop 会显示原来的窗口。系统没有托盘时（不支持 AppIndicator 的 Linux 桌面），关闭窗口即退出。

窗口使用系统自带的网页引擎：Windows 上是 WebView2（Windows 10 和 11 自带），macOS 上是 WKWebView，Linux 上是 WebKitGTK（远程桌面需要 GStreamer 的 H.264 解码器，Debian 和 Ubuntu 上是 gstreamer1.0-libav）。没有时应用会改在浏览器窗口中打开，命令行程序的 remohop app 也是如此。

在 Linux 上 remohop-app 链接了 GNU C 库（它要加载 GTK 来显示窗口）；在 Alpine 等 musl 系统上，请用静态链接的 remohop 运行 remohop app，它会在浏览器中打开应用。

快速协助

只想帮别人一次、不留下任何东西时，对方改为下载快速协助（RemoHop-QuickSupport.exe、RemoHop Quick Support.app、remohop-quick）：同一个程序，按名字以快速协助方式启动，立即共享屏幕，关闭窗口即退出。见快速协助。在 macOS 上，系统把 RemoHop 和 RemoHop Quick Support 当作两个应用，“屏幕录制”和“辅助功能”权限要分别授予（系统设置 > 隐私与安全性）。

安全

窗口是应用在 127.0.0.1 上提供的页面，地址中带随机令牌，保护措施与快速协助相同，其他机器无法访问。你连接的电脑显示在只有应用自己的页面才能嵌入的框架中。设计说明见 desktop-app.md。
