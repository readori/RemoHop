Licensing

RemoHop is dual-licensed: an open-source license and a commercial one. The license texts are what applies. This page is a reading aid.

Open source: GNU AGPL-3.0

Everyone may use, study, modify and redistribute RemoHop under the GNU Affero General Public License, version 3 only (AGPL-3.0-only). The full text is in LICENSE in the repository.

  • You may run RemoHop for any purpose, including commercially.
  • If you distribute RemoHop, modified or not, you must make the corresponding source code available under the AGPL-3.0.
  • Network use counts. If you modify RemoHop and let other people use it over a network, for example by running a modified remohop signal rendezvous server or a modified remohop web gateway for others, you must offer those users the source code of your modified version (section 13 of the AGPL-3.0).
  • Running an unmodified RemoHop, or using it only yourself, adds no obligation beyond the license's notices.

Commercial license

If the AGPL-3.0 does not fit your use, a commercial license is available from the copyright holder, the RemoHop project. Typical cases:

  • shipping RemoHop inside a closed-source product;
  • running a modified server for others without publishing your changes;
  • distributing it through a store whose terms conflict with the AGPL.

For commercial licensing, write to info@remohop.com. Say how you plan to use RemoHop (embedded in a product, as a hosted service, or distributed internally) and at roughly what scale.

This is separate from RemoHop Teams, the self-hosted team edition, which is sold per user at the prices on the pricing page. Using the open-source RemoHop needs no license from us, at work too.

Contributions

Because RemoHop is also offered under a commercial license, a contribution must be covered by a signed Contributor License Agreement (CLA) that lets the copyright holder distribute it under both licenses. You keep the copyright in your work. See CONTRIBUTING.md in the repository; questions about the CLA can go to info@remohop.com.

Third-party software

RemoHop links Go modules under the MIT, BSD-2-Clause, BSD-3-Clause, ISC and Apache-2.0 licenses, all compatible with the AGPL-3.0. Release archives will include their license texts as THIRD_PARTY_LICENSES.txt.

RemoHop does not include or distribute ffmpeg. The remote desktop runs the ffmpeg already installed on the host as a separate program. Anyone who bundles an ffmpeg build with RemoHop takes on that build's own license terms: ffmpeg with libx264 is under the GPL.

The VPN client on Windows needs the Wintun driver, which remohop neither includes nor downloads.

Do not remove existing copyright and attribution notices.
