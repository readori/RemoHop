RemoHop Teams: one policy for the people, devices and agents of a team

Groups, policies, single sign-on, admin approvals and central audit, on top of RemoHop. It runs on your own servers, inside your own rendezvous server, and the team's membership and policy are a log signed by your admins' keys, which the server can store but cannot forge.

See pricing Ask about Teams

Free for up to 5 users, then $5 per user per month, billed yearly. The Teams code is not open source; it is sold under a commercial license and built on the open-source RemoHop.

Who may reach what, in one place

People and their devices go into groups. A policy says which group of people may reach which group of devices, with which features, and which actions need approval. On each host the rule becomes a grant, which that host enforces itself.

AI agents are covered by the same policies, approvals and audit as people. They count as devices, not users.

What Teams adds

Everything an admin needs to run RemoHop for a team, with the team server kept out of the trust.

The team log

A log the server cannot forge

  • Every change to who may do what is an entry signed by an admin key the log allows to make it.
  • The log is append-only. The team server stores it and passes it on, but cannot forge an entry or a decision.
  • Hosts verify it themselves before they act on it; checkpoints and join codes let a new host start from a signed snapshot.

Groups

People, devices and groups

A team of people and their devices, groups of each, and a policy that connects them.

Admin

A console and a command line

The console runs on the admin's own machine and talks to the team server; the admin CLI does too.

Identity

Single sign-on and provisioning

Device enrolment signs in with OIDC or SAML 2.0; SCIM 2.0 brings people in from your identity provider.

Approvals

Admins can answer, with a signature

Actions a rule says need approval can be answered by a team admin, as well as by the host's owner; the host checks the signed decision.

Audit

Central audit and recordings

Hosts sign audit records into a hash chain and ship them, with session recordings, to the team server; retention is set there.

Server

Inside your rendezvous server

The team server runs inside your own remohop signal, and can meter relay traffic per team.

Plain facts

Your servers

Software you run yourself. There is no hosted version.

An offline license

A license file with an end date. Your server never calls us to check it.

Email support

With a Teams license, by email; not around the clock.

RemoHop underneath

The same encryption, grants and checks on each host as the open-source RemoHop.

No audit yet

RemoHop has had no independent security audit. Enterprise customers get help with their own security review.

Private code

The Teams code is not public, so this page describes it instead of linking to it.
