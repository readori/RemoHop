Download RemoHop

Every file is on GitHub Releases; the links below always fetch the newest release. All of them are listed in its SHA256SUMS, which is signed (see Verify a download).

Most people want RemoHop, the desktop app: one window to connect to your computers and to let others connect to this one. Someone who only needs help once takes Quick Support, which runs without installing anything. Servers and scripts use the remohop program; phones use the apps.

RemoHop and Quick Support

RemoHop is the desktop app: connect to other computers in tabs, let others connect to this one (every connection asks first), unattended access, a tray icon. Quick Support is for the person being helped: double-click, read the 9-digit ID and the temporary password to the helper, press Allow; closing the window ends it and nothing stays installed. See the quick support guide.

The remohop program

Host, client, browser gateway, rendezvous server and MCP server for AI agents in one static binary. The install scripts download the archive for your system and CPU, check it against SHA256SUMS (and that file's signature when cosign is installed) and copy remohop to ~/.local/bin or %LOCALAPPDATA%\Programs\RemoHop. They never use sudo. Read a script before you run it.

Linux and macOS

curl -fsSLO https://github.com/readori/RemoHop/releases/latest/download/install.sh
sh install.sh

Windows (PowerShell)

Invoke-WebRequest https://github.com/readori/RemoHop/releases/latest/download/install.ps1 -OutFile install.ps1
powershell -ExecutionPolicy Bypass -File .\install.ps1

Linux packages

.deb, .rpm and .apk for x86-64 and ARM64. Their names carry the version (for example remohop_1.0.1_amd64.deb), so take them from the release page. They install remohop and the systemd units and enable nothing; remohop service install starts a host at boot. More in Install.

Phone apps

For Android and iOS / iPadOS: connect to and operate your computers from a phone or tablet, with sessions that reconnect by themselves. The phone can be a host too: an Android phone can also be controlled if you allow it, and an iPhone or iPad can share its screen (view only).

Verify a download

Every file of a release is listed in its SHA256SUMS. That file has a keyless cosign signature: it proves that this repository's release workflow made it, for that tag, and the signature is recorded in the public Sigstore log. Download SHA256SUMS, SHA256SUMS.sigstore.json and your files into one directory, then:

sha256sum --ignore-missing -c SHA256SUMS
cosign verify-blob --bundle SHA256SUMS.sigstore.json \
  --certificate-identity-regexp '^https://github\.com/readori/RemoHop/\.github/workflows/release\.yml@refs/tags/v.+$' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com SHA256SUMS

On Windows, compare Get-FileHash FILE with the line in SHA256SUMS. The macOS downloads are also signed with a Developer ID and notarized by Apple; the Windows programs are not code-signed yet. Details: Install and the security model.
