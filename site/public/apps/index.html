English

Android 与 iOS 控制端应用

手机应用用来在手机或平板上连接并操作你的电脑。它们只是控制端：手机不能被控。

下载 iOS 应用：App Store（iPhone 和 iPad）。Android 应用已提交 Google Play 审核，审核通过之前可以自己从源码构建。

应用里有什么

两个应用的结构相同：一个原生外壳，加一个显示 remohop web 网关的 WebView。网关和 Go 核心直接运行在应用进程里，只监听手机自己的 127.0.0.1，所以会话仍然是手机和被控机之间端到端加密的点对点连接，中间没有 Readori 的服务器。

  • 远程桌面：查看并控制电脑屏幕，可以全屏、切换画质和显示器。
  • 终端：持久的 shell 会话，带 Esc、Tab、Ctrl、方向键等辅助按键。
  • 文件：浏览、上传、下载、新建文件夹、重命名和删除。
  • 剪贴板：在手机和电脑之间传文本。
  • 系统信息和截图。
  • 界面语言：应用及其页面都有简体中文和英文，默认跟随系统，可在设置里切换。
  • 设置（原生界面）：界面语言、汇合服务器地址和公钥、是否允许中继、设备名、本机身份指纹、用密码配对、已保存的主机。

目前的限制

  • 只是控制端。把 Android 或 iOS 设备作为被控机没有实现。
  • 没有内置服务器。要么在设置里填你自己的汇合服务器，要么用 主机:端口 直接连接。
  • 没有账号登录功能。
  • 两个应用每次改动都在 CI 中测试：iOS 应用在 iOS 模拟器中，应用内的测试用地址和密码连接一台 remohop host，在终端里执行一条命令，并在“文件”里列出一个目录；Android 应用在模拟器上，与一台真实的被控端配对，使用终端、文件、下载、剪贴板和桌面。如果在你的设备上遇到问题，请告诉我们。

应用和你的数据

应用只和两类对象通信：你连接的被控机，以及你在设置里填写的汇合服务器。身份密钥、配对令牌和设置保存在应用的私有目录里，不参与系统备份。应用里没有分析统计、广告或崩溃上报的 SDK。完整说明见隐私政策。

自己构建

Android

需要 Go、JDK 17 以上、Android SDK 和 NDK，并设置 ANDROID_HOME。默认生成 debug APK 并运行 JVM 单元测试：

mobile/android/build.sh

iOS

在 macOS 上先生成 Go 核心的 xcframework，再用 Xcode 构建工程：

mobile/ios/build-xcframework.sh
open mobile/ios/RemoHop.xcodeproj

第一次使用

  1. 在电脑上运行 remohop host，记下 ID（或地址）和密码。
  2. 在应用的设置里填入你的汇合服务器；和电脑在同一个局域网时可以不填，直接用 192.168.1.5:21118 这样的地址（电脑上用 remohop host --no-signal --listen :21118 启动）。
  3. 在连接页输入 ID 或地址和密码。勾选配对后，下次不需要密码。

遇到问题请看支持。真机上的问题报告对我们尤其有用。
