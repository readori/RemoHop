English

Android 与 iOS 应用

手机应用用来在手机或平板上连接并操作你的电脑。手机本身也可以被其他 RemoHop 设备观看：Android 经你允许后还能被控制；iPhone 和 iPad 只能被观看，因为 iOS 不允许任何应用控制设备。

App Store（iPhone、iPad） Google Play 即将上架

用手机控制电脑

两个应用的结构相同：一个原生外壳，加一个显示 remohop web 网关的 WebView。网关和 Go 核心直接运行在应用进程里，只监听手机自己的 127.0.0.1，所以会话仍然是手机和被控机之间端到端加密的点对点连接，中间没有 RemoHop 的服务器。

  • 远程桌面：查看并控制电脑屏幕，可以全屏，选择画质（原始分辨率或最高 2160p 到 480p）、帧率和显示器。
  • 终端：持久的 shell 会话，带 Esc、Tab、Ctrl、方向键等辅助按键。
  • 文件：浏览、上传、下载、新建文件夹、重命名和删除。
  • 剪贴板：在手机和电脑之间传文本。
  • 系统信息和截图。
  • 会话不会自己断：会话一直保持到你断开为止。手机切换网络、应用被挂起或短暂断网时，应用会自动重连，回到原来的标签页，终端接回同一个 shell。应用在后台被系统结束后，再打开时会用设备上保存的配对或密码，把当时打开的会话连回来。
  • 已保存的主机：配对过或记住了密码的电脑都在这里，保存的密码可以查看、复制或删除。
  • 界面语言：应用及其页面都有简体中文和英文，默认跟随系统，可在设置里切换。
  • 设置（原生界面）：界面语言、汇合服务器地址和公钥、是否允许中继、设备名、本机身份指纹、用密码配对、已保存的主机、诊断日志；iOS 上还有“通知”页。

让别人看这台手机

手机也可以作为被控端：打开后，桌面应用、浏览器控制台、命令行或另一台手机都能用它的 ID 和密码请求连接。每个请求都要你在手机上允许，并附防诈骗提醒；60 秒内没人回应就自动拒绝。对方只能看到屏幕（和基本系统信息），拿不到文件、剪贴板或终端。

目前的限制

  • iPhone 和 iPad 只能被观看，不能被控制：iOS 不允许任何应用控制设备。
  • 手机共享屏幕时只提供画面，没有文件、剪贴板和终端，也不共享声音。
  • 没有内置汇合服务器：在设置里填汇合服务器地址（你自己的，或官方的 signal.remohop.com），或者用 主机:端口 直接连接。
  • 还不支持账号登录。
  • 两个应用每次改动都在 CI 中测试：iOS 应用在 iOS 模拟器中，应用内的测试用地址和密码连接一台 remohop host，在终端里执行一条命令，并在“文件”里列出一个目录；Android 应用在模拟器上，与一台真实的被控端配对，使用终端、文件、下载、剪贴板和桌面。真机上的屏幕采集和控制还没有测试过。如果在你的设备上遇到问题，请告诉我们。

应用和你的数据

应用只和这些对象通信：你连接的被控机、你允许连接这台手机的设备，以及你在设置里填写的汇合服务器。身份密钥、配对令牌和设置保存在应用的私有目录里，不参与系统备份。应用里没有分析统计、广告或崩溃上报的 SDK。完整说明见隐私政策。

自己构建

Android

需要 Go、JDK 17 以上、Android SDK 和 NDK，并设置 ANDROID_HOME。默认生成 debug APK 并运行 JVM 单元测试：

mobile/android/build.sh

iOS

在 macOS 上先生成 Go 核心的 xcframework，再用 Xcode 构建工程：

mobile/ios/build-xcframework.sh
open mobile/ios/RemoHop.xcodeproj

第一次使用

  1. 在电脑上打开 RemoHop 桌面应用并允许连接，或者运行 remohop host，记下 ID（或地址）和密码。
  2. 在应用的设置里填入和电脑相同的汇合服务器（官方的 signal.remohop.com 或你自己的）；和电脑在同一个局域网时可以不填，直接用 192.168.1.5:21118 这样的地址（电脑上用 remohop host --no-signal --listen :21118 启动）。
  3. 在连接页输入 ID 或地址和密码。勾选配对后，下次不需要密码。

遇到问题请看支持。真机上的问题报告对我们尤其有用。
