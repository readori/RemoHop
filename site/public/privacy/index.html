隐私政策

最后更新：2026-11-24

本政策说明 RemoHop 软件、RemoHop 的 Android 和 iOS 应用、本网站，以及 Readori 运营的服务器如何处理数据。发布者是 Readori，联系邮箱 admin@remohop.com。

简短版本

  • 你的会话（屏幕、按键、文件、剪贴板、终端内容）在两台设备之间端到端加密。Readori 看不到，中继服务器也看不到。
  • 软件和应用不含分析统计、广告或崩溃上报组件，不向 Readori 回传任何使用数据。
  • 身份密钥、配对令牌和设置只保存在你自己的设备上。
  • RemoHop 没有内置的默认服务器。两台设备靠 ID 找到彼此时，需要一台汇合服务器，它必然会处理一些元数据：IP 地址、ID、连接时间。这台服务器由谁运营，这些元数据就由谁处理。
  • 账号是可选的。启用账号的服务器保存邮箱地址的哈希和你的设备列表。
  • 我们不出售数据，也不用它做广告或跨应用跟踪。

一、软件本身（remohop）

remohop 只与两类对象通信：你连接的对端设备，以及你自己配置的汇合服务器（remohop config set signal）。它不检查更新，不上报统计数据或崩溃信息。

它在本机配置目录里保存：本机的身份密钥、已保存主机的公钥和配对令牌、设置、剪贴板历史（如果你使用剪贴板功能），被控端还有审计日志。这些文件不会离开你的设备，权限为仅所有者可读。

被控机的主人能看到客户端发来的一切，这是远程控制的本意。连接别人的机器前请确认你信任对方。

二、Android 与 iOS 应用

应用是控制端。它在应用进程内运行一个只监听本机 127.0.0.1 的网关，直接与你连接的电脑建立加密会话，中间不经过 Readori 的服务器。

保存在设备上的数据

  • 设备的身份密钥、配对令牌、已保存主机的名称和地址、你填写的设置（汇合服务器地址、设备名等）。
  • 这些数据保存在应用的私有目录里。iOS 上该目录被排除在 iCloud 和本机备份之外；Android 上应用关闭了系统备份。
  • 应用内的网页视图不保留 Cookie 或缓存。输入的主机密码不会写入存储；应用运行期间可能和一个临时配对一起保存在内存里，用于断线后自动重连，应用退出即消失。
  • 卸载应用会删除上述全部数据。

诊断日志

  • 默认关闭。在“设置 → 诊断日志”中打开后，应用会在私有目录里记录自身的运行情况（连接步骤、错误、应用事件），大小上限约 1 MB。关闭即删除日志。
  • 日志会去掉密码、令牌和密钥；被控端的 ID、名称和 IP 地址会保留，因为排查连接问题需要它们。
  • 日志不会自动离开设备，只有在你选择“分享”或“给客服发邮件”时，才发给你选定的对象。

系统权限

  • 本地网络（iOS）：用于直接连接你局域网里的电脑。
  • 相机和照片（iOS）：只在你选择上传照片或视频到远程电脑时，由系统自带的选择器访问。选中的文件发往你连接的那台电脑，不发往 Readori。
  • 剪贴板：只在你使用应用里的剪贴板功能时读取或写入，内容发往你连接的那台电脑。
  • 网络访问（Android）：用于建立连接。
  • 通知（Android）：用于显示“已连接到……”常驻通知，让会话在后台保持连接，并可从通知中断开。

应用不做的事

应用不收集分析数据，不含广告或第三方 SDK，不读取通讯录、位置、麦克风或设备广告标识符，不做跨应用跟踪。应用里目前没有账号登录功能。

通过 TestFlight 或应用商店安装时，Apple 或 Google 会按它们各自的隐私政策处理安装、诊断等数据，并可能在你同意的情况下向开发者提供匿名的崩溃报告。这部分不由本政策约束。

三、汇合服务器与中继

只有当你把设备指向某台汇合服务器时，下面的数据才会被处理。如果这台服务器是你自己或第三方运营的，适用的是该运营者的声明，Readori 接触不到这些数据。用 主机:端口 直接连接时，不涉及任何服务器。

以下内容适用于 Readori 运营的公共汇合服务器。它的地址公布后会列在本页。源码仓库里的 RemoHop 不带默认服务器，不会自动连接到 Readori 的服务器；如果某个官方发布的构建内置了默认服务器，我们会在这里和发布说明里写明。

服务器看不到的

设备之间的连接是端到端加密的。服务器不能读取或修改你发送的内容，看不到你的屏幕和文件，也得不到你的密码。经中继转发的连接同样如此：中继转发的是密文。

服务器处理的数据

  • 注册为被控端的设备：设备的身份公钥、9 位 ID、在线期间的 IP 地址、最后一次在线的时间。
  • 连接请求：哪个 IP 地址查询了哪个 ID。
  • 经中继的连接：双方设备的 IP 地址、开始时间、持续时间和数据量。
  • 经 websocket 入口的连接：由 Cloudflare 报告的你的 IP 地址、连接时间和数据量。
  • 如果你创建了账号：邮箱地址的哈希、你各台设备的公钥和名称，以及账号的签名设备列表。你的邮箱地址用于发送登录码；登录码不会被保存。

日志与保留期限

服务器的日志记录设备上线和下线、经中继的连接和 websocket 连接，包含上面列出的 IP 地址和数据量。日志保留 14 天，之后删除。每小时的统计只有计数，不含 IP 地址。连续 90 天未使用的 ID 会被释放，对应的注册记录随之删除。

处理这些数据的目的

提供服务本身；把服务控制在限额之内（按地址的并发上限和每月流量预算）；阻止滥用。在适用《通用数据保护条例》（GDPR）的地区，处理依据是履行你所请求的服务，以及我们保障服务安全、防止滥用的正当利益。

四、本网站

本网站是纯静态页面，不使用 Cookie、分析脚本、第三方字体或任何第三方资源，也没有表单。和所有网站一样，托管服务商（Cloudflare）在提供页面时会处理你的 IP 地址和请求信息，用于传输和安全防护。

五、你发给我们的邮件

你写信到 admin@remohop.com 时，我们会收到你的邮箱地址和信件内容，只用于回复和处理你的请求。请不要在邮件里发送密码、配对令牌或私钥。支持邮件最长保存 24 个月，你可以随时要求提前删除。

六、共享

我们不出售数据，也不与广告商或数据经纪商共享。上述服务器数据只会交给为我们提供基础设施的服务商（服务器托管商；承载 websocket 入口和本网站的 Cloudflare；启用账号时用于发送登录码的邮件服务商），以及在法律要求时提供给有权机关。

七、你的选择

  • 运行你自己的汇合服务器（remohop signal），让设备指向它。见自建服务器。
  • 在设备上关闭中继：remohop config relay off，或在应用的设置里关掉“Allow relayed connections”。
  • 删除账号：remohop account delete --yes。
  • 生成新的身份、放弃旧 ID：remohop key gen --yes。
  • 查询、更正或删除与你有关的数据，或者反对处理：写信到 admin@remohop.com。服务器上的数据是按 IP 地址、ID 或身份公钥记录的，请在信里提供相应的标识，以便我们找到它。你也有权向所在地的数据保护机构投诉。

八、未成年人

RemoHop 是面向技术用户的工具，不面向 13 岁以下的儿童，我们也不会有意收集儿童的数据。

九、变更

本政策有实质变化时，我们会更新本页顶部的日期。历史版本可以在源码仓库的提交记录里查到。

十、联系

关于隐私的问题、删除请求和滥用举报：admin@remohop.com。
