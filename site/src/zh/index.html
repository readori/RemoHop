有边界的 AI 代理

授权是一份带限制的凭据，在代理要操作的那台机器上签发。那台机器在每条命令、每次文件操作时检查它，代理那边怎么做都扩大不了权限。

授权允许什么，代理就只能做什么

写明功能、命令、目录和时限。没列出的一律拒绝，包括给自己创建一个比授权活得更久的配对。

--allow --cmd --for --approve --record

你批准，否则谁也不行

用 --approve each，每条命令、每次文件改动都等你批准；用 first，每个会话的第一次要批准。被控机的终端会问你，Linux 和 macOS 会弹出通知，在任何终端里都能用 remohop host approve 回答。30 秒没人回答就自动拒绝。

拒绝时说明原因，一条命令全部停下

代理可以查询自己能做什么；每次拒绝都写明是哪条限制、哪个授权，代理就能待在边界之内。remohop host panic 在被控机的任何终端里都能执行，立即暂停所有授权、结束所有代理会话。

命令白名单是护栏，不是沙箱：能启动别的程序的命令会把这种能力一起带进来。保护的边界（英文）

可以验证的信任

汇合服务器按 ID 帮两台机器找到对方。之后画面、键盘、文件和命令都走 QUIC 直连，只有两端能读。实在打不通时，中继转发的也是同样的密文。

工作原理 安全模型

端到端加密

QUIC 加 TLS 1.3，登录用 CPace：密码从不在网上传输，中间人无法完成登录。

默认直连

先打洞、请路由器映射端口；只有运营者开启了中继、其他办法都不行时才走中继。

服务器看不到内容

它知道哪些 ID 在线、它们的地址和何时连接，但看不到两端之间传的东西。

每次连接都先问你

新设备附防诈骗提醒；允许的设备默认只能看屏幕，其余的要你勾选。

常见问题

在公司用 RemoHop 要付费吗？

不用。开源版任何用途都免费，包括商用，也从不检查你怎么用。用来管理整个团队的 RemoHop 团队版才是付费版本。

需要注册账号吗？

不需要。账号是可选的，只用来把你自己的设备归到一起；同在一个账号里，不会因此获得任何访问权限。

汇合服务器能看到我的屏幕吗？

不能。它只负责牵线，需要中继时转发的也是密文。它能看到元数据：哪些 ID 在线、它们的地址、何时连接。

哪些 AI 代理能用？

任何能启动 stdio 服务器的 MCP 客户端，例如 Claude Code、Claude Desktop、Cursor 和 VS Code。另有六个 Agent Skills，教代理使用命令行。

支持哪些系统？

Windows、macOS 和 Linux 既能被控也能控制别人，另有 Android 和 iOS 应用。Android 手机可以被控制；iPhone 和 iPad 只能共享屏幕。Linux 上的屏幕采集需要 X11，不支持原生 Wayland 桌面。
