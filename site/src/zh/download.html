RemoHop 与快速协助

RemoHop 是桌面应用：在标签页里连接其他电脑，让别人连接这台电脑（每次连接都先问你），无人值守访问，托盘图标。快速协助给被协助的人：双击，把 9 位 ID 和临时密码念给协助者，点“允许”；关闭窗口即结束，不留任何安装。详见快速协助说明。

命令行程序 remohop

被控端、客户端、浏览器网关、汇合服务器和给 AI 代理用的 MCP 服务器，都在这一个静态链接的程序里。安装脚本会下载与你的系统和 CPU 对应的压缩包，用 SHA256SUMS 校验（如果装了 cosign，还会校验该文件的签名），然后把 remohop 复制到 ~/.local/bin 或 %LOCALAPPDATA%\Programs\RemoHop。脚本从不使用 sudo。运行前请先读一遍。

Linux 和 macOS

curl -fsSLO https://github.com/readori/RemoHop/releases/latest/download/install.sh
sh install.sh

Windows（PowerShell）

Invoke-WebRequest https://github.com/readori/RemoHop/releases/latest/download/install.ps1 -OutFile install.ps1
powershell -ExecutionPolicy Bypass -File .\install.ps1

校验下载

发布版本里的每个文件都列在 SHA256SUMS 中。这个文件带有 cosign 无密钥签名：它证明文件出自本仓库针对该标签运行的发布工作流，签名记录在公开的 Sigstore 日志里。把 SHA256SUMS、SHA256SUMS.sigstore.json 和你下载的文件放在同一个目录，然后执行：

sha256sum --ignore-missing -c SHA256SUMS
cosign verify-blob --bundle SHA256SUMS.sigstore.json \
  --certificate-identity-regexp '^https://github\.com/readori/RemoHop/\.github/workflows/release\.yml@refs/tags/v.+$' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com SHA256SUMS

在 Windows 上，用 Get-FileHash 文件名 算出哈希，和 SHA256SUMS 里对应的一行比较。详见安装和安全模型。
