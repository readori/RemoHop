AI agents, with guardrails

A grant is a credential with limits, issued on the machine the agent will work on. That machine checks it on every command and every file operation, so nothing on the agent's side can widen it.

An agent gets what the grant allows, and nothing else

Name the features, the commands and the folders, and how long. Anything not listed is refused, including making itself a pairing that would outlive the grant.

--allow --cmd --for --approve --record

You approve, or nobody does

With --approve each every command and file change waits for you; with first, the first one of each session. The host's terminal asks you, Linux and macOS show a notification, and remohop host approve answers from any terminal. A request nobody answers is refused after 30 seconds.

Refused with a reason, stopped in one command

The agent can ask what it may do, and every refusal names the limit and the grant, so it stays inside them. remohop host panic suspends every grant and ends every agent session at once, from any terminal on the host.

A command allow-list is a guard rail, not a sandbox: an allowed program that can start others carries that power along. Limits of the protection

Details

Trust you can check

The rendezvous server introduces the two machines by ID. After that the screen, keys, files and commands go over a direct QUIC connection that only the two ends can read. When no direct path exists, a relay forwards the same ciphertext.

How it works Security model

Encrypted end to end

QUIC with TLS 1.3, and a CPace login: the password never crosses the network, and a man in the middle cannot complete it.

Direct by default

Hole punching and router port mapping first; a relay only if its operator turned it on and nothing else works.

The server sees no content

It sees which IDs are online, their addresses and when they connect, and never what passes between them.

Every connection asks first

New devices come with a scam warning, and an allowed device only sees the screen until you tick more.

Questions

Is RemoHop free to use at work?

Yes. The open-source edition is free for any use, commercial use included, and it never checks how it is used. RemoHop Teams, for managing a whole team, is the paid edition.

Do I need an account?

No. Accounts are optional, and they only group your own devices; being in an account grants no access to anything.

Can the rendezvous server see my screen?

No. It introduces the two machines and, if a relay is needed, forwards ciphertext. It sees metadata: which IDs are online, their addresses and when they connect.

Which AI agents work with it?

Any MCP client that starts a stdio server, for example Claude Code, Claude Desktop, Cursor and VS Code. There are also six Agent Skills that teach an agent the command line.

Which systems does it run on?

Windows, macOS and Linux as hosts and controllers, and Android and iOS apps. An Android phone can be controlled; an iPhone or iPad can only share its screen. On Linux, screen capture needs X11, not a native Wayland desktop.
