Support and contact

RemoHop is an independent open-source project. Write to us, or find us on Telegram:

{{SUPPORT_EMAIL}} Telegram: @remohop

Write in English or Chinese. Use email for security reports and anything with logs attached. A small team maintains this project, and there is no guaranteed response time.

Check these first

  • The troubleshooting guide explains errors one by one: cannot connect, password refused, no direct path, mounts, VPN, a black remote desktop, ffmpeg and encoders.
  • remohop <ID> ping shows whether the path is lan, direct, punched or relayed. Most connection problems show their cause there.
  • Put -v before any command (or set REMOHOP_DEBUG=1) to get debug logging on stderr.
  • Status and limits on the Features page lists the platforms and features known to be untested.

What to include in a report

  1. The output of remohop -v <the failing command> on the client.
  2. The output of remohop status, remohop log and remohop config on the host.
  3. The output of remohop version, or the commit you built from.
  4. The operating system and version on both sides. For the mobile apps, the device model and OS version.
  5. The network on both sides: home broadband, office network, mobile data, any proxy, and whose rendezvous server you use.
  6. What you expected to happen and what happened.

Remove secrets before you send. Do not send us passwords, pairing tokens, the contents of identity.key, the token in a gateway URL, or a Cloudflare Access secret. You may also redact IDs and public IP addresses if you prefer.

Security issues

If you find a vulnerability, please do not disclose it in a public issue or forum. Write to {{SUPPORT_EMAIL}} with “security” in the subject. Include the affected version or commit, steps to reproduce, and the impact as you see it. We will reply to confirm receipt and agree a disclosure date with you once there is a fix. The security model is described on the Security page.

Other matters

Commercial licensing
Write to {{EMAIL}} and describe your use. See Licensing.
Privacy and data deletion
See the privacy policy. The apps and the software send us no data. To delete an account on a RemoHop server, run remohop account delete --yes or write to us.
Abuse reports
If someone is abusing a server operated by the RemoHop project, send us the time (with time zone) and the IP addresses or IDs involved.
