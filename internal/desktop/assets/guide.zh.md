# 使用说明

## 开始使用 {#start}

RemoHop 让你连接自己的其他电脑，也让你信任的人连接这台电脑。每个连接都是端到端加密的；没有密码、没有你的同意，谁也进不来。

### Windows {#start-windows}

1. 解压下载的文件，双击 **RemoHop.exe**。
2. RemoHop 尚未做代码签名，所以第一次运行时 Windows SmartScreen 可能会警告。点 **更多信息**，再点 **仍要运行**。
3. Windows 防火墙可能询问是否允许联网。在大多数网络中，无论怎么回答都能连接。

### macOS {#start-mac}

1. 打开下载的 `.dmg`，把 **RemoHop** 拖到“应用程序”文件夹，再从那里打开。
2. 要让别人看到这台 Mac 的屏幕，先在 **系统设置 › 隐私与安全性** 中允许 RemoHop：**屏幕录制** 用于显示屏幕，**辅助功能** 用于鼠标和键盘。“屏幕录制”要在重新启动 RemoHop 后才生效。
3. **RemoHop Quick Support**（快速协助）在 macOS 上是另一个应用，同样的两项权限要单独授予它。

### Linux {#start-linux}

解压下载的文件，运行 `./remohop-app`。它的窗口使用 WebKitGTK；没有 WebKitGTK 时，RemoHop 会在浏览器中打开，用法完全一样。

### 第一次启动 {#start-first}

RemoHop 会询问语言和**汇合服务器**。汇合服务器按 ID 为电脑牵线：

- **官方服务器**：由 RemoHop 运营，无需设置。不确定就选它。
- **我自己的服务器**：你或你的公司运行的服务器地址。
- **不用服务器**：只能在同一网络中按地址连接。

如果马上有人要帮你，勾选 **现在就允许别人连接这台电脑**。这两项之后都可以在[设置](#settings)中更改。

关闭窗口后 RemoHop 仍在托盘（macOS 上是菜单栏）中运行，别人仍然可以连接。托盘菜单中的 **退出** 会结束 RemoHop 和所有连接。

## 连接一台电脑 {#connect}

打开[连接](app:connect)页面，或使用首页上的**快速连接**。

### 按 ID 连接 {#connect-id}

输入对方电脑的 9 位 ID（显示在它的首页上），点 **连接**。两台电脑必须使用同一个汇合服务器。

### 按地址连接 {#connect-address}

在同一网络中，或者不用服务器时，输入地址和端口，例如 `192.168.1.5:21118`。

### 本网络中的电脑 {#lan}

**本网络中的电脑** 列出附近运行 RemoHop 并允许连接的电脑。不需要服务器，也不用输入：点它旁边的 **连接** 即可。显示“连接”页面时，列表每隔几秒刷新一次。

标有 **密钥已变** 的电脑自称是你保存过的某台电脑，但密钥不同。它可能是冒充的：先和它的主人核实，再连接（见[密钥已变](#trouble-key)）。

### 密码，以及记住一台电脑 {#connect-password}

电脑在窗口中打开后会要求输入它的密码：对方主人念给你的密码，或它首页上显示的密码。

勾选 **记住这台电脑**，下次连接就不用再输密码。RemoHop 会和它配对；无法配对时（快速协助、另一台电脑上的 RemoHop 应用），就把密码保存在这台电脑上，直到那个密码改变。

接着，RemoHop 应用和快速协助会询问那台电脑前的人：对方看到是谁在连接，然后点 **允许**。大约一分钟内没人回答，连接就会被拒绝。

### 已保存的电脑 {#saved}

连接过或配对过的电脑都列在 **已保存的电脑** 中，并显示是否在线。**已配对** 的电脑不用密码。它的菜单（**⋮**）可以 **重命名**、查看或删除保存的密码、**移除**，以及在同一网络中把它从睡眠中唤醒（设置 **网络唤醒地址** 后点 **唤醒**）。

### 打开的电脑 {#connect-open}

每台打开的电脑都列在边栏的 **已打开的电脑** 下。**⧉** 把它移到单独的窗口；**×** 断开并关闭它。连接断开（睡眠、换了网络）后会自动恢复。

## 让别人连接 {#incoming}

### 允许别人连接 {#incoming-allow}

在[首页](app:computer)打开 **允许别人连接**。首页随即显示这台电脑的 **ID** 和 **临时密码**，都带 **复制** 按钮。把它们告诉帮你的人，不要告诉其他人。

临时密码每次启动 RemoHop 时都会换新；**换一个** 立即更换。在 **密码设置** 中可以改用 **我自己的固定密码**，它一直不变，直到你修改（至少 8 位，包含字母和数字）。无论哪种，每次有人连接都会先问你。

### 同意一个连接 {#approval}

有人请求连接时，**连接请求** 会出现在所有窗口的最前面，显示对方自称的名称、它的密钥和连接来源。

> **新设备** 会附带提醒：如果有人打电话自称客服、银行或警察，让你安装这个软件，请点 **拒绝**。那是诈骗。

除非你勾选 **控制鼠标和键盘** 或 **传输文件、使用剪贴板**，对方**只能看你的屏幕**。按 `Esc` 等于 **拒绝**；一分钟内没人回答的请求会被自动拒绝。

勾选 **记住这台设备**，在允许连接打开期间，这台设备下次会以相同的权限直接连入，不再询问。

### 谁在连接 {#sessions}

[会话](app:sessions)页面显示等你回答的请求，以及 **当前连接** 的每个人。**控制** 和 **文件** 可以立即打开或关闭对应的权限。只能查看的设备可以从它那边请求更多权限，这时会再问你一次。

**已记住的设备** 无需询问即可连入。可以用同样的开关修改它们的权限，也可以 **重命名** 或 **移除**。

### 结束连接 {#ending}

- 设备旁的 **断开** 结束它的连接。
- **全部断开** 结束所有连接。
- 只要有人连接着，屏幕角落就有一个红色小横幅，始终显示在所有窗口之上，带 **断开** 按钮。
- 关闭 **允许别人连接** 会结束所有连接，也不再让任何人连入。

### 无人值守访问 {#unattended}

想在没人时也能连上这台电脑，就在首页打开 **无人值守访问**，并设置一个强密码（至少 12 个字符，包含小写、大写、数字、符号中的三种）。**生成强密码** 可以帮你生成一个。知道无人值守 ID 和这个密码的人**无需询问**即可连接，请妥善保管。

它作为后台服务运行，开机即可用。开关开启时为绿色，关闭时为红色。**连接** 显示通过它连接的人，**修改密码** 更换密码。它的 ID 和密码在 **设置 › 无人值守 ID 与密码** 中；在 Windows 上，服务有自己的 ID。

在 Windows 上，这些操作都会请求管理员授权，因为服务属于管理员。

## 远程桌面 {#desktop}

打开的电脑有 **远程桌面**、**终端**、**文件**、**剪贴板** 和 **信息** 几个标签。

### 远程桌面工具栏 {#desktop-toolbar}

- **仅查看** 停止发送你的鼠标和键盘操作。对方只允许查看时，**请求控制** 会征求对方主人的同意。
- **适应窗口** 让画面适应窗口大小；**全屏** 占满整个屏幕。
- **刷新画面** 重新获取一帧完整画面。
- **Ctrl+Alt+Del** 发送你自己的电脑会拦下的这个组合键。
- 画质菜单：**原始分辨率**，或最高 2160p 到 480p。网络慢时选小一些更流畅。
- 帧率菜单：**自动帧率**，或 30 到 144 fps。
- 对方有多个显示器时会出现显示器菜单。
- **统计** 显示分辨率、编码、码率和延迟。
- 画面停止时会出现 **重新连接**。

先点一下画面：画面获得焦点时，键盘输入会发往对方电脑。

### 完整查看器 {#desktop-viewer}

在终端中运行 `remohop <ID> desktop` 会在浏览器中打开功能更全的查看器。它在本机绘制远程鼠标指针，指针跟手、没有延迟，另外还有：

- **Lock mouse**（锁定鼠标，或按 `Ctrl+Alt+Shift+M`），适合游戏和 3D 应用：鼠标留在画面内，发送的是移动量。按 `Esc` 或再按快捷键释放。打开 **Auto lock** 后，远程应用隐藏指针时，下一次点击画面就会锁定。
- **Audio** 在本机播放对方电脑的声音；**Mute** 静音。
- **Record** 把看到的画面录制成本机上的 MP4 文件。
- 组合键、输入文字、画质预设，以及锁定、屏蔽输入或黑屏对方屏幕。

### 屏幕共享组件（ffmpeg） {#ffmpeg}

被共享屏幕的电脑需要 ffmpeg。没有时，在允许别人连接期间首页会提示；文件和命令仍可使用。

在 Windows 和 macOS 上，**安装屏幕共享组件** 会下载 RemoHop 指定的 ffmpeg 版本，使用前用 RemoHop 内置的指纹校验，并显示进度。你不点就不会下载任何东西。在 Linux 上请用包管理器安装，例如 `sudo apt install ffmpeg`。

## 文件、终端和剪贴板 {#files}

- **文件** 浏览对方电脑：**上一级**、**新建文件夹**、**上传…**（或把文件拖到列表上），每个文件都可以 **下载**、**重命名** 或 **删除**。已有的文件不会在没问你的情况下被替换：**跳过**、**保留两者** 或 **替换**。
- **终端** 在对方电脑上打开命令行。**新建会话** 再开一个；连接断开后会话仍在运行，可以从会话菜单中重新选择它。**复制** 复制选中的文字，**粘贴** 粘贴。
- **剪贴板**：**读取远程剪贴板** 把对方的文字取过来（**复制到本设备**）；**发送到远程** 把文字放到对方的剪贴板。
- **信息** 显示对方的系统信息，**截图** 拍下它的屏幕。

每一项都需要对方允许：文件和剪贴板需要对方勾选 **传输文件、使用剪贴板**。

## 快速协助 {#quick}

只想帮别人一次时，对方使用 **RemoHop 快速协助**：什么都不会留在电脑上，关闭窗口就全部结束。告诉你要帮助的人：

1. 从 remohop.com 下载 **快速协助** 并打开（Windows 上点 **更多信息**、**仍要运行**；Mac 上允许“屏幕录制”和“辅助功能”）。
2. 保持 **使用官方服务器**，除非你给了对方你自己服务器的地址。
3. 把 **本机 ID** 和 **密码** 念给我，不要告诉其他人。
4. 我的请求出现时，核对名称，然后点 **允许**。
5. 结束后点 **停止共享**，或者关闭窗口。

然后你在[连接](app:connect)页面用这个 ID 和密码连接。除了看屏幕之外你能做什么，由对方窗口里的开关决定：鼠标和键盘、文件和剪贴板（默认打开），运行命令和访问网络（默认关闭）。

## AI 智能体 {#agents}

AI 智能体可以通过 RemoHop 在一台电脑上工作，而不必拥有全部权限。在那台电脑上，`remohop host grant NAME --for 2h --allow ...` 给它一个只允许你列出的操作、有时间限制的凭据；`remohop host revoke NAME` 收回它，`remohop host panic` 立即结束所有智能体会话。智能体通过 `remohop mcp` 连接。详见 [remohop.com 上的 AI 智能体](web:docs/ai-agents)。

## 设置和更新 {#settings}

- **汇合服务器**：官方、自己的，或不用（见[第一次启动](#start-first)）。
- **语言** 和 **外观**：“自动”跟随系统。
- **开机自动启动**：登录后 RemoHop 在托盘中启动。
- **更新**：RemoHop 每天从 remohop.com 读取一次最新版本号，不发送这台电脑的任何信息，也不会在你不知情时安装任何东西。有新版本时，页面上方会出现一条提示，提供 **立即升级** 或 **下载**，以及 **更新内容**。
- **诊断日志**：**导出** 会在“下载”文件夹中保存一个文本文件，出问题时发给支持团队。密码、令牌和密钥会被去掉。你不发送，它就不会离开这台电脑。

## 遇到问题 {#trouble}

### 没有设置汇合服务器 {#trouble-noserver}

ID 要通过汇合服务器查找。请在[设置](app:settings) › **汇合服务器** 中选择一个，或者改用电脑的地址（`主机:端口`）连接。

### 对方离线，或 ID 不存在 {#trouble-offline}

和那台电脑前的人核对 ID：那里必须正在运行 RemoHop，并且打开了 **允许别人连接**，两台电脑还必须使用同一个汇合服务器。睡眠中的电脑是离线的；在同一网络中，可以用它菜单（**⋮**）里的 **唤醒** 叫醒它。

### 连不上服务器 {#trouble-server}

首页显示 **无法连接** 服务器，或 **离线：正在重试…**。检查这台电脑的网络，以及[设置](app:settings) › **汇合服务器** 中的地址（首页上的 **汇合服务器设置** 链接直接通往那里）。在同一网络中也可以按地址连接。

### 屏幕共享需要 ffmpeg {#trouble-ffmpeg}

被共享屏幕的电脑上没有 ffmpeg。在那台电脑的首页点 **安装屏幕共享组件**（Windows 和 macOS），或在 Linux 上用包管理器安装。见[屏幕共享组件](#ffmpeg)。

### 密钥已变 {#trouble-key}

那台电脑回应的密钥与这里保存的不同。如果它的主人重装了 RemoHop 或电脑，就在 **已保存的电脑** 中（**⋮**）**移除** 它，再用它的密码重新连接。如果没有重装，不要连接：可能有人在冒充它。

### 密码错误，或被拒绝 {#trouble-password}

临时密码在那台电脑每次启动 RemoHop 时都会改变：请向对方要当前的密码。“被拒绝”表示对方点了 **拒绝**，或者一分钟内没人回答。

### 仍然解决不了 {#trouble-more}

**设置 › 诊断日志 › 导出** 保存一份报告；通过 **帮助与支持** 或 Telegram 发给我们。
