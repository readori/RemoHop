  The gateway sees everything you do here. How this works
  
        How this works. A browser cannot hole-punch or speak RemoHop's QUIC session, so this page talks to a gateway
  (remohop web) and the gateway speaks the normal P2P session to the host. That session is end-to-end encrypted between the gateway and the host,
  but the gateway sees everything: the screen, every keystroke, files, the clipboard and any password you type here.
  Use only a gateway you control. Exposing one beyond localhost requires TLS and its own login; anyone who logs in to a gateway can use its saved pairings.
